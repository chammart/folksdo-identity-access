# Folksdo IAM™ Provider Admin Experience

Independent Nuxt 4 Provider administration application for Folksdo IAM.

## Local development

```bash
pnpm dev:provider-admin
```

The application runs on `http://localhost:3200` and expects Folksdo IAM at
`FOLKSDO_IAM_BASE_URL` (default `http://127.0.0.1:3100`).

Authentication and Provider authorization remain enforced by Folksdo IAM.
